Privacy Policy

Last updated: 2 May 2026

TL;DR: Roundtable Cast does not collect, store, or transmit any user data to Cristiano Cavo or any third party. No analytics, no telemetry, no accounts. Your API keys live in macOS Keychain. Conversations live on your Mac.

Data handling

API keys

API keys you enter into Roundtable Cast are stored locally in the macOS Keychain. They are never transmitted to Cristiano Cavo. They are sent only to the provider you configured (Anthropic, OpenAI, Google, OpenRouter, Groq, or Mistral) as part of authenticated API requests.

Conversations

All conversations, bot personas, and table state are stored locally inside the app's sandbox container at ~/Library/Containers/com.strawberry.roundtable.mas/. They are never transmitted to Cristiano Cavo.

Network requests

When you start a conversation, Roundtable Cast sends LLM API requests directly from your Mac to the provider you configured. Cristiano Cavo is not a party to these requests and does not receive a copy of any prompt, response, or metadata. The provider's privacy policy applies to those requests:

  • Anthropic
  • OpenAI
  • Google (Gemini)
  • OpenRouter
  • Groq
  • Mistral

Crash reports

If you have opted in to share diagnostics with app developers in macOS System Settings, Apple may forward anonymized aggregate crash data through App Store Connect. Cristiano Cavo receives no personally identifying information through this channel.

Analytics

None. Roundtable Cast contains no analytics SDK, no telemetry, and no remote logging.

Children

Roundtable Cast is not directed at children under 13. The app rating is 4+ for its UI; however, the LLM providers' content is generated dynamically and may not be appropriate for all ages. Parental oversight is recommended.

Changes

If this policy changes, the updated date at the top of this page will reflect the change. Material changes to data handling will be announced via app update release notes.
