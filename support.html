Getting started

I need an API key. Where do I get one?

Roundtable Cast supports six LLM providers. Sign up directly with the provider of your choice — most offer a free tier:

  • Anthropic Claude: console.anthropic.com
  • OpenAI: platform.openai.com/api-keys
  • Google Gemini: aistudio.google.com/apikey (generous free tier)
  • OpenRouter: openrouter.ai/keys (one key, many models)
  • Groq: console.groq.com/keys
  • Mistral: console.mistral.ai/api-keys

How do I add my API key?

Open Settings (gear icon, top-right), pick a provider, paste your key, click Save. The key is stored securely in macOS Keychain.

Why don't I see any output?

Most common causes:

  • API key missing or invalid → check Settings
  • No internet connection → check network
  • Provider rate limit / quota exceeded → check the provider's dashboard
  • Less than 2 bots configured → add at least 2 bots in the sidebar

Tips

How do I get better conversations?

Persona text is everything. Be specific about voice, length, and quirks. "Reply in 1–2 short sentences" works. Vague personas make vague bots.

What's the difference between round-robin and moderator mode?

Round-robin cycles through bots in order — predictable, cheap. Moderator mode uses a small extra LLM call to pick the next speaker based on context — better for storytelling. Costs around 30% more tokens.

How do I export a conversation?

Toolbar top-right, Export icon. Save as Markdown, plain text, or JSON. Or copy to clipboard.
